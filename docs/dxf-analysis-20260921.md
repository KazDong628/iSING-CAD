CL60、182、202 对象数分别减少 10.66%、7.35%、2.44%。CL60 的 RMS 从 4.080 降至 2.336 mm；但**总轮廓长度差从 0.433 增至 30.047 mm**，不能称为各项指标全面改善。旧总长接近可能来自不同局部偏差的相互抵消，不能取代位置和形状比较。202 的改进量很小，不能宣称显著提高精度。

## 主要问题

1. **拟合分段过多，参数不稳定。** 旧拟合每段最多前探 99 个顶点；密集像素轮廓会把长直线或长弧拆碎。短弧对边界抖动敏感，局部半径接近某个 OCR 数值也不能证明对应关系。新算法减少了一部分片段，但大量边界抖动仍来自分割掩膜本身。
2. **比例推断和 OCR 解析有缺陷。** CL60 旧直径端点估计为 6.011304 px/mm，与六条独立长度证据冲突；新结果采用 5.847090 px/mm，保留 3.48279% 的冲突及舍弃原因，没有放宽 3% 共识门限。182 的 `⌀840+4` 等完整单边公差曾被漏解析，修复后得到 7.453345 px/mm。231 仍存在 OCR 漏项和尺寸线被文字打断的问题，比例未唯一确定。
3. **GT 也有单位、闭合和范围问题。** 182 原始 GT 的 `INSUNITS=0`，不能直接按毫米评分。其严格端点图含取整缝隙和一处约 45.650009 原绘图单位的最近端点距离，不能称为 45 mm，也未在评分时修补。四图 GT 均含命名的闭合假设层，报告保留它们在完整评分中。
4. **完整材料外形与简化主轮廓的目标不同。** 202 最大误差位于底端预测弧和 `BENCHMARK_TREAD_CLOSURE` 水平线之间。原图确实绘有凸出的踏面，预测保留该凸起，GT 将该处简化；不能把约 24 mm 全归因于分割错误。基线 GT 核心曲线到预测的单向最大误差仍为 8.861 mm，故也不能宣称核心轮廓已准确。单向覆盖误差不惩罚多余预测几何，不能替代完整双向评分。
5. **二值分割不等于参数化建模。** 本地 U-Net 输入尺寸为 768；按旧比例计算，CL60、202 一个网络像素约对应 0.70、0.86 mm。上采样不会补回原图细节。现有尺寸 API 主要解析、核对 OCR，未建立完整的长度、半径、角度与相切约束方程；请求成功不能证明毫米参数正确。

## 已实施的修改

- 在源轮廓顶点上建立候选直线/圆弧，用动态规划选择较少的有效片段；候选构造和评估均有数量上限。源顶点不移动，每条候选使用完整源点支持及原有容差。
- 继续使用原保真门和拓扑检查。231 的 52 段候选超出原预算，明确拒绝，重新验证后保留原 56 段结果，没有通过放宽误差来压缩对象。
- 同一半径标注兼容多个弧时撤销冲突绑定，保留歧义证据。
- 严格支持带直径/半径前缀的完整单边公差；对直径推断与独立长度共识进行交叉检查。
- 增加可下载的 DXF 独立审计页面，展示原始/过滤对象数、长度/圆心/半径/弧角、连接、候选对应和逐段误差。修复了互补半圆可能被误配的问题，未知单位和未计算结果不显示为毫米精度或零误差。

原始数据和 GT 只读，GT 仅在预测完成后用于审计，不参与比例、轮廓或 API 输入。

## 下一步优先级

先统一并审核“完整材料外形”与“标注定义的主轮廓”监督范围，尤其是踏面闭合区域、182 的单位和断点；评分协议若需要改变，应另建版本并保留旧结果。随后在分割得到的零件 ROI 上利用原分辨率边缘和边界监督改善角点、窄槽、端部，再把有明确箭头/尺寸线证据的标注绑定到几何图元，联合求解尺寸与相切约束。新增未参与开发的图纸用于验证泛化，不能为当前四张写入 GT 参数获取通过。
