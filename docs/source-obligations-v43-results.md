# V41–V43：缺失 LINE、尺寸站位及求解检查点迭代

实验输入为原图、OCR 和 GT DXF 派生的栅格掩膜。GT DXF 坐标不进入预测或在线模型。两张图纸均为已曝光开发样例，独立留出样本为零；重放与完整上游运行分别记录。1.5 mm 为新增参考形状检查，原 0.1 mm、1 mm 和精确半径/角度/G1 条件保留。

## 三个实际代码问题

1. **候选被自己的预约状态阻断。** 生产调度在多个步骤重复调用有副作用的访问过滤器。V41 改为在阶段内复用首次预约结果，并在首个可执行范围处停止枚举。使用真实 `SearchBudget` 的回归覆盖了首轮及后续轮次；未选中的范围不再提前标记为已访问。
2. **局部修复创造了同站位别名，反而丢失原尺寸。** 恢复下方 LINE 后，044 同一条直径引出线上出现上下两个理论交点。V42 只对同一窄笔画、测量轴位置差不超过该笔画宽度且距尺寸线最近的有限关联唯一的情况，选择尺寸线最近的关联，保留所有别名和证据。不同笔画、宽站位、同距竞争和缺失证据仍未解决。该规则选择动态锚点，不固定图像坐标，也没有强迫别名坐标相等。真实源输入复核中，r006 的候选数从 2 降为 1，恢复 Ø285 公差中点策略及其显式 Ø186 依赖关系。
3. **求解有了有效部分解，却不再重试未绑定 R。** V42 的 R114 有唯一箭头目标，但从最初拟合解出发的有界搜索失败。诊断使用已经通过源检查的九半径解作数值初值后，R114 成功求解并通过移动后圆弧的源标注复核。V43 接入一次检查点重试：原图、原问题域、源预算和所有已知等式保持；最多重试一个半径、局部阶段 90 秒，随后重新在线绑定并进行最多 120 秒的正式联合求解。旧失败回执继续保留，新失败则返回原有有效解。

数值检查点只是初值，不是新的优化域。新的半径必须经独立源复核、在线重新绑定、旧约束保留、原始源检查及最终 DXF 回读。新增 API 调用在单独账本中记录，不把继承的源证明计为当前 API 新确认。
