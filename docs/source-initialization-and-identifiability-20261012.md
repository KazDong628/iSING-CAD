# 标注驱动重建：初始解、约束充分性与本轮修复

日期：2026-10-12。测试对象为已曝光开发图 HDSA-65-main、044-main。

## 1. 目标与当前结论

目标流程是：原图、OCR、GT 派生的栅格掩膜 → 初始 LINE/ARC 链 → 标注与对象、测量位置、关系绑定 → 已知值固定 → 未知属性联合优化 → 发现缺项或冲突后修改拓扑或绑定，再求解 → 原生 DXF 回读与独立 GT 评估。

拟合的端点、圆心、半径和方向是数值初始状态。核实后的 R 和角度由标注决定，不能为了贴合掩膜改小 R 或改变斜线角度。未知属性可以通过约束求解，但不能保证只要对象数量相同就能唯一恢复 GT。

本轮修复了真实的优化目标及迭代状态问题；没有证明两张图都达到完整 GT 标准。在线 API 成功、数值子集可行、发布成功和完整重建成功必须分别报告。

## 2. 为什么对象数量正确仍不够

一个已知 R176 的圆，圆心仍有两个位置自由度，有限圆弧还有起止位置和分支问题。把某条斜线固定为 12°，也没有同时确定它的位置和长度。只有圆与相邻对象的连接、相切、尺寸站位等条件足够独立，才能进一步确定这些属性。

还需要同时核实：

1. 类型与循环顺序：相同数量的 LINE/ARC 可以连接成不同轮廓。
2. 有限范围：箭头指向一段圆弧，不能把跨两个设计圆弧的粗拟合对象直接整体锁为一个 R。
3. 分支：圆心在弦的哪侧、顺逆时针、小弧还是大弧，是离散选择；连续优化不能自动替换错误分支。
4. 测量语义：尺寸可能量到圆角前两条支撑线的理论交点、剖面位置、圆心、极值或投影站位，而非当前 CAD 节点。
5. 方程独立性：读出了很多数字不等于增加了同样数量的独立约束。冗余尺寸、未绑定尺寸和软掩膜项不能填补硬约束秩。
6. 可辨识性：局部形状自由度大于零意味着已知方程不足。即使局部自由度为零，也需检查其他离散分支；它不自动证明全局唯一解。

基线 V69 中，HDSA 的 22 个对象为 10 LINE＋12 ARC，12 个 R 已精确，但仅绑定 19/37 条识别尺寸，仍有 14 个形状自由度。044 的发布结果为 10 LINE＋11 ARC，精确 R 为 11/13，绑定尺寸 18/36，形状自由度仍有 19。继续重复同一欠约束问题的优化，只会在多个允许形状之间移动。

## 3. 逐流程定位

### 3.1 初始对象与局部拓扑

分割只提供对象划分和初始拓扑假设。斜线容易被大半径弧吞并，小圆角容易被短直线或尖角替代。局部修复需要将新增斜线、两侧接触对象及圆角作为一个候选，并在保留已知约束的前提下联合求解。仅有像素支撑的拓扑候选，还不是已参数化的 CAD。

本轮 V71/V72 的 044 从旧 V62 状态恢复，在新增 R6 对象后联合求解预算耗尽，只留下拓扑草稿；原生导出没有可引用的已绑定标注证书。其外形最大误差下降不能算属性或重建能力改进。失败记录保留，未计为通过。

V73/V74 从当前 V69 的匹配几何、绑定及解继续，尝试重新验证此前的 R6 状态。这个上游变化在报告中明确列出，所以不能把各版本差异解释为单因素实验。是否恢复证书，以新的原图复核结果为准。

### 3.2 标注解析与测量图

当前 API 的绑定选择受本地候选枚举限制。若本地没有表示正确的测量位置，API 无法从候选中选出正确方程。

本轮在线回执进一步区分了这一点：HDSA 的分页绑定可出现两页 HTTP 和结构解析均成功，但总状态仍为 `partial_inventory_coverage`，因为部分源记录没有可发送的候选；这不是分页联网失败。044 的 API 能给出 R16/R13 的像素提案，提案却未成为通过原图验证的箭头；模型给出了坐标不等于归属链已经核实。

HDSA 多条 10、25、70、71 等尺寸出现 `measurement_endpoints_not_represented`；部分直径与参考剖面关系未建立，`r049` 作为参考直径仍未独立求解。一些记录虽然能构造相对站位方程，却不能据此声明绝对轴线位置已确定。存在 OCR 或公差语义歧义的记录也不能直接强制锁定。

已发布 HDSA 的 g002 为 LINE，对竖直轴的锐角约 13.3505943°，对应 r035 标注 12°。当前缺口不是没有看到 12°：有可核实候选，也产生过固定 12° 的联合数值候选，但其原图发布检查未通过，因此未替换已有草稿。不能把旧草稿的 13.3506° 计作满足该标注。

044 的剖面尺寸、理论站位和右侧闭合特征同样存在缺口。R16（r017）、R13（r028）的箭头归属或有限区间尚未可靠建立。它们不能被“当前拟合半径差不多”替代，也不能因为未检测到箭头就宣布豁免。

需要补强的核心是独立于 CAD 节点的测量图：尺寸线、延伸线、箭尖、支撑对象、理论交点、圆心及剖面站位。未知站位必须由对象和约束定义，不能把像素测得的坐标直接硬锁进模型。

### 3.3 相切关系

端点重合只保证位置连续，不保证切向连续。已承认的 G1 方程在 DXF 中严格回读，未承认的接点不能计入该通过数。

V69 HDSA 有 15 条已承认 G1，另有 3 个曲线接点未获得足够原图切向证据，涉及 g003/g004、g005/g006、g013/g014。044 有 9 条已承认 G1、7 个未确定接点；部分是短跨度、笔画缺失或多轨歧义，g004/g005 还出现原图非相切的正向证据，不能一律强制所有曲线接点相切。

原先局部二次多项式对曲率较大的圆弧估计端点切向会有偏差。本轮增加双尺度原图圆形笔画导数观测：先验证径向与相位残差、转角、弓高和两个窗口的稳定性，再使用观测切向；近直线、非圆曲线和不稳定窗口仍拒绝。这项观测拟出的 R 只用于切向测量，绝不进入半径标注绑定。

真实 HDSA 预检的三个缺失接点仍未被此方法补回；不能把合成圆弧测试通过说成实际相切覆盖已经完整。

### 3.4 求解目标不一致

原流程在使用原图笔画目标的同时，还惩罚端点、自由圆心偏离旧拟合 CAD 坐标。这让初始拟合属性继续影响最终属性。标注修正需要移动接点时，该额外惩罚会把解拉回旧位置。

现在，在标注优先且有有效原图观测时，去除这份旧拟合坐标惩罚。保留原图笔画目标及明确声明的掩膜软定位，保持原变量范围、圆弧分支及所有已知方程。没有有效原图观测时仍记录旧模式的软坐标正则化，不能声称这条回退路径也完全摆脱了拟合影响。

审计还发现：最终求解有原图观测，部分拓扑预检、半径试探、半径检查点最终求解及新增约束求解却没有。这些阶段实际在优化不同目标。本轮将原图观测传入这些路径；重新观察可以以当前解为搜索中心，原问题的范围和输入证据不被重置。

### 3.5 数值迭代状态丢失

标注优先模式的数值预算原先只负责中止优化。即使初始状态或中间迭代已满足全部已绑定方程，预算耗尽后也直接保留初始轮廓，丢失严格可行的数值状态。

V73 增加可行点保存：

- 初始状态及 SLSQP 迭代点均重新检查当前全部约束，包含相关的依赖方程与有限测量域。
- 同时检查圆弧弦长、方向分支、几何合法性、原变量范围、位移上限及其他优化不等式。
- 只保存全部通过的点，以相同的原图/掩膜目标选择其中较好的数值状态；不读取 GT 分数。
- 预算耗尽或优化不收敛时，可以保留已完整核验的可行点，但不声明最优性。
- 原图支撑校验、原生半径/角度/相切与尺寸回读仍在发布路径中独立执行。数值可行不等于允许发布。

相关测试专门验证：坏的后续状态不会覆盖可行点；新标注改变方程时，旧状态不能使用旧证书冒充新问题的解；预算耗尽且没有可行点时，原有拒绝行为保留。

### 3.6 圆角复核缺少证据输入

两条已有半径复核路径调用有限区间检查时，没有传入原图灰度像素和规范化 OCR 记录。对于通过原图构造的圆角，复核函数会在证据缺失时直接拒绝。V74 补齐这两项输入，并向后续有限箭头归属检查传递当前已检查的半径区间；求解后的圆角和相邻对象仍来自同一个当前几何状态。

这个修复不意味着圆角必定通过。044 的 R6 手动源证据诊断中，实际圆弧笔画支撑率约 0.58974，仍低于未改动的 0.60 要求。应区分缺少输入造成的提前拒绝和读取真实像素后的支撑不足。测试覆盖原图输入正确传递及新的正向、负向复核结果，不绕过负向结果。

### 3.7 整圆与无限直线不能替代有限对象

原图笔画数值目标原先对 ARC 计算到整圆的径向距离，对 LINE 计算到无限直线的垂距。同一个圆上不属于当前圆弧范围的点、直线端点之外的点都可能产生零残差。这不能正确约束圆弧分支、端点范围和线段长度。

V74 改为到有限 LINE/ARC 的距离。为允许重新求解接触位置，同一笔画可以由原有共享节点的相邻对象解释；没有拓扑邻接关系的其他对象不能吸收这份笔画。保留原半径、角度、相切方程以及独立的最终原图支撑门槛。定向测试覆盖错误圆弧范围、直线延长线、合法接点迁移和不相邻对象冒领笔画。

### 3.8 一条复核失败导致整个参数化阶段停止

V73/V74 的 044 中，R6 的局部支撑失败使恢复函数抛出异常，普通重建随之进入 `parametric_unavailable`，没有机会在其他已核实约束下继续联合求解。新运行的 DXF 因此只保留拓扑草稿，不能借用上游的 11 个精确半径证书宣称本次也已验证。

V75 将完整检查点复用与普通候选继续求解分开。完整检查点仍要求全部旧约束重新通过；普通路径只有在原输入及完整逐项审计有效时，才提取其中已通过的子集并再次独立复核。完整失败证书保持 `passed=false`，失败项和待修复原约束逐条保留，不能计入已满足。源输入不匹配、证书被改动或审计中断仍然拒绝。

对箭头唯一归属、OCR 半径已核实、两侧为 LINE 且有真实局部笔画检查的构造圆角，局部几何支撑失败可以进入一次有界的固定 R 数值试探。它不是正式标注绑定：移动接点后必须重做局部原图检查、完整已知约束检查、正式在线绑定及 DXF 回读。已有半径试探路径原先只接受 `requires_topology_repartition`，导致已构造圆角的接点修复永远无法进入。

## 4. 验收与 GT 差异

044 现有简化参考的右侧闭合没有包含原图的全部 R6/R16/R13 特征。补回原图 R6 会增加 ARC，因此既不能用旧 GT 的对象数强制删除 R6，也不能用这一局部冲突解释全部几何误差。原图约束完成度与既有 GT 一致性分别报告，数据集保持只读。

本轮保留 0.1 mm 严格检查、1 mm 对照检查和 1.5 mm 补充目标；半径的精确回读标准不因轮廓误差目标变化。不能只展示叠图或平均误差，必须同时查看最大误差、完整对象参数、邻接关系、原生约束及未绑定记录。

## 5. 后续算法的正确反馈方向

若硬约束残差不通过，检查冲突、错误关联、离散分支及数值求解；若形状自由度仍大于零，优先补测量图和缺失关系；若已有方程全部满足但原图支撑失败，检查自由接点、未绑定尺寸和观测歧义，不能修改已核实的 R/角度来换外形；若原图完成而旧 GT 冲突，保留两类结果并明确冲突位置。

大模型应参与读原图、局部放大、解释尺寸测量位置、提出对象/关系修正和比较竞争候选。确定性内核负责约束、几何构造、联合优化和原生回读。增加 API 次数无法替代缺失的对象表示、测量语义和数值状态保存。

下一步精度改进应优先针对尚未表示的测量位置，而非继续重复相同半径 OCR：为每个未绑定尺寸建立有原图证据的理论交点、支撑线、圆心、极值或剖面站位；把这些符号位置随未知对象一起求解。随后按约束秩增加独立关系，对离散对象划分和圆弧分支另做候选遍历。对于未知公差内尺寸，构造目标采用什么约定也必须声明；合法公差内的多种几何并不自动等于同一个 GT。

## 6. 本轮实际结果

实际测试表及逐条未绑定记录由 `runtime/cad-controlled-20261008/source-initialization-v75-review.html` 与同名 JSON 汇总。报告保留 V69 对照及本轮 V71/V72/V73/V74/V75 全部尝试，区分已发布结果和最后一次未发布候选。

在线测试之外，另对 HDSA 和 044 分别运行固定上游在线标注的离线数值诊断。这些诊断不调用新的 API，也不读取 GT。044 的这次诊断保存了满足已绑定数值方程及全局原图门槛的候选，但 R6 重新做局部圆角检查仍失败；不能用全局通过覆盖局部失败，更不能计作一次新的在线完成。

测试范围是两张开发图的在线最终阶段重放，复用冻结 OCR 和上游拓扑；不是新样本的完整网页端到端测试，也不构成与云端 GPT 等效的能力证明。GT 只在预测选择、导出及哈希冻结后由独立评估进程读取。

本轮流程修复没有带来可宣称的 GT 精度提升。十次新在线重放全部保留，加上两行 V69 对照共十二行；完整目标通过为零。最终生产代码回归结果为 2218 passed、3 skipped、2 warnings。源输入、上游回执、冻结代码和评估前后预测哈希均按运行记录复查；数据集没有改动。

### 6.1 离线数值诊断揭示的验收矛盾

本轮共保留五组离线诊断，均未调用新 API，不能计为在线完成。HDSA 的 V75 离线延续保留此前仅按原图支撑和原生方程选择的候选；它满足 12 个已绑定 R、4 个角度和已承认的 G1，但原图支撑 0.9094455852 仍低于 0.9109016393。候选选择、导出和哈希冻结后，独立 GT 评估得到最大误差 1.0905223314 mm。它达到 1.5 mm 补充几何目标，却未达到当前原图发布门槛，也未解决所有源尺寸及 G1 覆盖。

另建独立实验代码快照 `source-conditioning-v76-code`，仅将标注优先分支的标量目标与梯度同时乘以同一个正数，诊断目标尺度对 SLSQP 的影响；相对权重、约束及验收门槛不变。它没有纳入生产代码。044 的全局支撑率由固定绑定诊断的 0.8756894357 提升到 0.8836518047，R6 局部检查仍失败；冻结后的独立 GT 最大误差为 2.9336506548 mm。HDSA 也没有获得更好的源证据通过状态。

这些对照说明两个不同问题：对未绑定的形状自由度，仅降低原图像素损失不能保证接近 GT；对已严格满足标注的候选，相对于旧拟合轮廓的笔画支撑下降，也不能直接证明 CAD 属性错误。后续应完善测量图和可辨识性，并研究与原图成像不确定性相符的几何证据。不能把已失败门槛改成通过、把离线候选冒充在线完成，或使用 GT 误差在运行时挑选预测。
