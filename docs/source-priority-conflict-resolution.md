# 原图标注优先的冲突处理

当前目标是：掩膜提供轮廓对象和邻接关系的初始假设，属性由原图标注解析、有限对象绑定和联合求解确定。不能把初始拟合半径、角度或掩膜位置当成已知设计参数。

## 本次修复的冲突

1. **已知标注与栅格掩膜的位置冲突。** 工作台及受控运行显式采用 `source_annotations_before_mask_v1`。已核实的尺寸和关系仍为硬约束；掩膜进入软定位目标。原掩膜最大误差、阈值和失败标记均保留，明确记录是否参与发布门槛。参考 DXF 精度检查没有改变。
2. **正确初始解被计算预算逻辑拒绝。** 以前有界重启、多初值和半径候选求解都依附于掩膜硬约束的存在。现在计算时间和目标函数调用上限由独立预算管理。重启仍检查原变量范围、对象 ID、遍历方向、圆弧分支和共享端点；不会以新解重新定义原优化域。预算耗尽保留原几何，不声称数学不可行。
3. **初始几何与最终绑定错配。** 恢复任务时同时核验原图哈希、已接受的解、对应绑定和原生精确约束，再恢复求解后的几何。五份状态快照有哈希校验，原始优化域单独保存。
4. **旧的粗拓扑与新设计拓扑冲突。** 在两个已有半径的粗 ARC–ARC 接点之间恢复有标注的有限 LINE 时，旧的“相邻圆弧推断相切”不能继续被当成同一个节点约束。只有在两端原图半径重新确认、有限斜线角度重新确认、两处新 G1 经原图与原生方程核验后，才允许把旧的推断关系替换为新路径。明确标注/要求的旧关系不可借此删除。
5. **局部修改丢失已知尺寸。** 候选插入圆角、恢复斜线之后都检查已验证义务的类型、记录、数值、对象归属、锚点方向及硬约束等级。失去旧义务的候选不能仅凭 overlay 较好就替换当前解。
6. **拒绝新候选时丢失有效绑定状态。** 恢复任务生成可重新认证的完整检查点。后续候选失败时保留上一套对应的几何、绑定和解，避免保留图形却把尺寸验证重置为零。补读未绑定箭头只触发完整重认证，不直接清空已知子集；当前原图确有正向矛盾时撤销旧绑定。检查点复用仍执行当前原图证据检查、精确方程检查和 DXF 重新导出回读。
7. **把候选清单哈希变化当作原图矛盾。** 在线重绑定时，检测器未检出旧标注会改变清单内容，但原图、OCR 和已核实对象可能没有变化。标注优先模式会逐条重认证旧绑定的原生方程和有限归属，重新比较当前正向矛盾，并将经认证的义务保留进新求解。最终发布门槛只在完整来源重认证通过时允许保留旧检查点；不以字节差异替代语义证据，也不跳过新候选的求解与源图核验。API 弃权与本地来源重认证分别记录。

代码入口：`reconstruction_priority.py`、`source_state.py`、`source_relation_replacement.py`、`source_topology_initial_guess.py`、`parametric_solver.py`、`parametric_pipeline.py`。工作台通过 `service.py` 显式启用标注优先模式。

## 不会自动消失的冲突

- 044 原图右侧的 R6、R16、R13 在现有简化 GT 闭合及其栅格掩膜中没有完整表达。按当前目标保留原图义务；不能为了匹配 GT 而删除标注，也不修改 `__dataset/`。补全这些对象后，源标注正确性和旧参考轮廓一致性仍可能给出不同结论。
- OCR 值、箭头目标或有限对象边界不明确时，不能把拟合值补成标注，也不能仅凭模型回答强行认证。未解决项继续计入分母。
- 原图笔画支持和掩膜贴合是不同证据。移除掩膜硬门槛不等于移除原图核验；严格方程成立但偏离原图的候选仍不能直接发布为正确结果。
- 全部已绑定约束成立只说明该子集可行。缺失的尺寸、未知接点、未识别的小圆角、剩余形状自由度仍须分别检查。
