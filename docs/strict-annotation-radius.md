# 基于源标注的严格半径重建

本流程的数值来源是原图 OCR 及经过核验的标注指向关系。在线模型负责解释和提出局部操作，几何执行器和数值优化器负责生成实际 LINE/ARC。参考 GT DXF 不进入预测构建或模型请求。

## 处理链

1. 分割或人工确认的材料掩膜生成初始 CAD，保留 `baseline-*` 原始草稿。
2. 所有后续拓扑候选直接使用初始掩膜的 `extraction.raw_polyline_px`；不反复拟合已经近似的 CAD 来代替原始观察。基线候选仍保留初始 CAD。
3. 在线半径定位 Agent 查看原图与 OCR 局部图，只提出原图像素坐标中的箭尖和引线点。最多两轮，第二轮只复核尚未得到原像素证据的记录，各轮单独留存。提案不是绑定结论。
4. 本地在原始分辨率验证文字关联、引线连续墨迹、箭头方向及锥度、轮廓接触和目标唯一性。允许在有完整证据时处理穿过其他轮廓的真实引线。模型像素定位存在小偏差时，可在有界邻域用原图 Hough 线段纠正，再完整复核；不能使用预期 R 或 GT 选择目标。额外拒绝同时贯穿文字框继续长距离延伸、又属于至少三条近等间距平行笔画的剖面线假引线；单凭穿框或附近有平行线不足以否决。
5. 拓扑编辑 Agent 根据源图、当前编号和未解决标注提出合并、拆分、类型修正或圆角插入。几何执行器支持直线及圆弧支撑的小圆角，以及有两到三条已核实半径标注的相邻圆弧重新分段；外端点保持，内部连接点从原掩膜观察搜索。候选独立检查并评估，不把编号附近的整段自动视为同一个设计圆弧。
6. 通过源证据准入的圆弧绑定标注数值。求解器将该 R 从自由变量中消去，作为常数构造圆心和共享端点；显式检查弦长可行性。其余自由几何量及有证据的约束联合优化。形状目标使用不可变原始掩膜折线的双向距离，允许源点在当前图元及相邻图元间匹配，避免强行保留初始 CAD 的错误分段点；优化目标不替代独立源图与边界误差硬检查。
7. 独立检查闭合、自交、单位、源图支持、原掩膜表示误差和约束满足度。回读 DXF 的原生 ARC 半径，再与标注值作数值精确相等检查，半径容差为 0。

进入编辑循环前，先核验规划器选择的候选。若其未通过源图检查，仅能从通过同一检查的候选或保留基线中选择工作图；没有有效工作图时不执行编辑。编辑器接收实际通过验证的几何及匹配预览，原规划回执保持不变。循环结束后再次检查，前置检查不代替最终验收。

## 箭尖与整段圆弧分别核验

真实箭头只能证明它指向的源位置。粗拟合 ARC 可能跨过 R176 与 R40 等不同曲率的转接，不能因为箭尖落在该图元上，就把整段锁成同一个 R。绑定器增加 `fixed_nominal_radius_source_interval_v1` 检查，保留六项来源约束：

1. 先根据文字、箭头和当前图元选择唯一目标，再做整段检查；不按拟合 R 与标注 R 的接近程度重新选择目标。
2. 用初始 `extraction.raw_polyline_px` 中与图元对应的连续区间作为观察，覆盖整段而非只看箭尖附近；没有可用源区间时不能确认整段绑定。
3. 固定 OCR 标注 R，只搜索圆心，并检查区间内的最大径向残差。既不改写标注值，也不在绑定阶段修改预测几何。
4. 保留原始源边界误差预算，并计入离散采样间隔的保守余量；存在初始掩膜预算时优先使用该预算，不能拿更宽的箭尖接触带代替。
5. 拟合后的标注圆仍须与已核实箭头方向一致，沿用 0.88 的径向对齐要求。同时保存固定当前端点的弦长可行性及源残差诊断，允许后续联合求解调整连接点。
6. 整段检查失败时标记 `requires_topology_repartition`。该标注仍属于已确认、必须解决的半径要求，但不计为已绑定；重新分段后必须重新核验，不能删掉要求或把未知状态当作豁免。

这是一项有界可行性检查，不证明全局求解成功，也不代替后续原图笔画、闭合、自交、原始掩膜预算和 DXF 回读检查。候选求解值正确与当前可下载 DXF 满足合同必须分别记录。

剖面线与粗轮廓的交点也可能产生局部锥度，并且整条剖面线确实有连续墨迹。因此，所有箭头入口还统一检查文字归属：只有同一笔画连续贯穿 OCR 框、继续延伸到框外，并且属于至少三条近等间距平行笔画组成的家族时，才否决其作为该文字引线的证据。真实半径引线可能越过文字延伸至圆心，所以单独穿框或长延伸都不能据此拒绝；两条平行线也不足以认定周期剖面线。拒绝原因保留在 `radius_source_rejections`，不会转成“没有箭头”的豁免。

## 半径文字覆盖分母

半径覆盖先检查提供的完整 OCR 文字清单，再检查箭头与图元。`recognized_radius_records` / `recognized_count` 包含能解析的 R 标注及保守识别出的疑似 R 文字。`R1O`、`R?`、缺值、R0、负半径或原文字与 parsed 元数据矛盾，均以 `unresolved_radius_text` 留在未解决分母中；不猜数、不改写 OCR、不生成数值约束。Ra 表面粗糙度和普通英文说明不因此转成半径要求。

`unresolved_radius_text_records` 与未知箭头分开记录；任一种未知都不能获得全量通过。该分母覆盖已经提供的文字记录，不声称原图 OCR 召回率完整；完全漏掉的原图文字仍需要独立文字覆盖审计。

## 完成与失败的含义

- `constraint_subset_accepted`：一组已绑定约束通过求解，可导出经过检查的部分参数化草稿。
- `radius-contract.json` 中的 `candidate_satisfied`：候选解的 R 与疑似 R 文字记录均已解决、数值精确满足；不能由此认证当前下载文件。
- 发布合同的 `satisfied`：R 与疑似 R 文字记录的来源覆盖完整，已绑定 R 精确满足，且对应 DXF 已回读、成套发布。`current_dxf_verified` 和 `publication_status` 明确回执是否对应当前文件。其他尺寸及 GT 精度仍单独检查。
- `completed_with_unresolved_radii`：已保存部分参数化产物，但仍有未核实箭头、目标歧义或未完成的圆角拓扑。工作台提示需要检查，不冒充完整尺寸验证。
- `candidate_rejected`：独立检查失败。保留上一套有效草稿，不能将该草稿归因于成功的尺寸求解。

检测不到箭头与证实不存在箭头是不同状态。当前自动流程将前者保留为未知，不能自动豁免其半径要求。没有来源验证的近邻半径、模型口头判断或恰好相等的拟合值均不足以证明绑定正确。

编辑或评估响应结构失败不代表拓扑已经收敛。只使用原有最多三轮中的剩余轮次重试，保存每轮失败及之前的有效草稿；没有有效提案和独立几何检查时不会采用任何修改。

若两个不同 R 被绑定到同一个圆弧，求解直接报告冲突；不能取平均值或折中半径。如果 R 正确但使源图检查失败，仍保留失败记录。GT 参考阈值、掩膜误差预算以及其他维度的固定容差不会因为半径硬约束而放宽。

## 厚笔画支持度修正

源图检查采用 `source-stroke-support-v2`。原 Canny 距离只度量黑线两侧的边缘，会把厚黑线中心误判为没有支持。新版额外核验实际黑墨、相反梯度的双边缘夹持、轮廓方向一致性、有限笔画宽度和 OCR 区域排除。白色间隔、单侧边缘、大块填黑和方向错误的剖面线不能借此通过。

`edge_supported_fraction` 及旧距离指标保持原义，新指标另存为 `stroke_supported_fraction`。比较双方都有同版本回执时才使用新指标，否则统一回到旧指标，避免新旧混比。允许下降 0.035、原像素距离/方向容差、原始掩膜表示预算及独立 GT 门槛均保持不变。旧实验不重写；新版检查须在新的实验目录重跑。

## 2026-10-06：分段搜索与求解目标

相邻两到三段标注圆弧的重分段不再只保留一组最小掩膜残差的连接点。执行器保留有界的离散分界候选，并分别尝试最大误差和均方误差联合优化；每个候选仍固定外端点、严格使用已核实 R，并检查完整原始边界的双向误差。只有这些检查通过的候选才能按原图笔画支撑排序。排序分数不能作为接受证书，全轮廓仍须通过原来的发布检查，误差预算和支撑门槛没有放宽。

求解器的原始边界先验改用 1024 个按物理弧长均匀分布的中点。前向残差按源边界区间长度加权，反向残差按图元弧长加权，共享节点和自由圆心的软正则也按相邻图元弧长分配。这样，相同轮廓被拆成更多小段、或者掩膜顶点密度不同，不会凭空增加这些位置的目标权重。精确 R 的常量消元、弦长可行性和最终验收条件保持不变。

含圆弧的唯一共享节点还可从原始闭合掩膜提出相切假设，避免只根据已经失准的拟合切向筛掉真实接头。三尺度源路径切向须在 2° 内稳定、两侧在 3° 内相切，随后以这些源路径为观察窗口重新检查原图单一墨迹；原图两侧也须满足既有 3° 条件。角点、开放掩膜、剖面线歧义或墨迹不足均弃权。已有可信关系保持，先前失败证据保留；掩膜平滑本身不能直接生成相切硬约束。

预检失败另存 `source-validation.json` 和 `source-support-diagnostics.json`，后者列出每个图元及从起点到终点四个区段的笔画支撑。下一轮在线编辑只接收白名单诊断；历史编号明确属于此前候选。源图预检失败意味着绑定和求解尚未执行，反馈记录 `comparison_status=not_run`，不再把尚未执行的步骤解释为“丢失已有约束”。局部诊断用于定位问题，不能证明 GT 一致，也不能批准几何。

完成求解后的检查另存 `solved-source-validation.json`。保持求解器的真实成功/失败状态，再报告源图、原掩膜预算或构造半径保存失败；不能把后验失败改写成约束不可行。编辑反馈可提供构造半径的历史 ID、原值、实际值及漂移量，但明确 `binding_verified=false`。

有完整一致构造元数据、原值已精确且圆心/端点自洽的构造弧，后续求解保留其数值几何不变量，与正式新绑定 R 冲突时拒绝。该保持不会向正式半径约束清单或完整标注合同增加记录，未知目标仍为未知；诊断分别报告数值优化自由度与标注证据剩余自由度，不能靠固定未认证参数冒充满约束。

## 审计产物

| 文件 | 用途 |
| --- | --- |
| `radius-targets.json` | 在线源像素提案、未知记录、HTTP 与结构回执 |
| `constraint-bindings.json` | 源证据、准入约束、完整 R 覆盖与未解决记录 |
| `parametric-solution.json` | 数值方法、精确半径合同、候选及最终实体、残差与几何验证 |
| `radius-contract.json` | 来源覆盖、零容差半径与 DXF 回读检查 |
| `workflow-provenance.json` | 输入和产物哈希、掩膜来源、实际执行阶段、在线/本地分工 |
| `parametric-stage.json` | 持久化进度、失败原因、最后有效产物的发布记录 |

工作台公开结构化模型回答与本地检查结果，不展示私有思维链。

GT 派生掩膜实验单独声明为条件性开发实验，仅检验给定完整材料区域后的重建能力。先冻结预测，再独立比较 GT；不把此类实验算作真实分割或未见样本的端到端成功。
