# 源标注控制的 CAD 重建：当前开发候选

## V15：多步修复与当前产物证书

V14 的两幅完整在线实验没有通过联合参数化验收，最终保留源拓扑草稿；失败候选中的绑定数、自由度或求解检查不能认证这些草稿。各轮原始产物及失败仍保留，完整对照见主项目 `runtime/cad-controlled-20261008/strict-joint-review-20261010.html`。V15 是后续开发候选，是否合入主项目取决于回归与在线复测，不能因单元测试通过就宣称 GT 精度达标。

V15 在非末轮完成两个源证据有效的预检后，若已有不同几何、尚需继续修复的中间图，可将剩余兄弟候选标为 `deferred_not_run`，让其后续修复优先获得下一轮机会。被延后的操作仍可重试；探索中间图不能发布。任何拟发布子图还必须保留最后可信结果的正式约束，最终原图重检回退也禁止升级未联合认证的中间图。原有 600 秒起始预算、条件扩展规则、轮数、18 次预检上限和所有源图/求解门槛均未放宽；单次运行中的预检仍不能强制抢占，因而不是严格实时截止保证。

半径箭头搜索还修复了内部候选截断问题：先在声明的局部观察域内筛选与 OCR 有邻接或射线关联的线段并去重，再检查枚举上限。存在第 25 个未检查的竞争假设时，前 24 个中的唯一成功不能成为唯一归属证据；内部搜索不完整时，外层也不能提交部分成功观察。HDSA 与 044 的同输入源图重放分别保持 12 条、12 条有观察证据的半径记录；这只是像素观察覆盖，并非正式绑定或在线参数化成功。冻结 V14 HDSA 的两个 r032 观察触发过内部截断，只能认定其唯一性审查不完整，不能据此认定物理箭头选错。

恢复任务时，当前 CORE 的实际模型和原生 DXF 将重新核算全部已发布方程，包括半径、距离、横竖、轴角、两实体/三点角和相切，沿用求解器的既有协议与阈值。半径、其他数值方程、关系及完整性各有独立证书；其他方程失败不会把已精确核实的 R 错报为未解。新失败尝试的约束、覆盖率、自由度和传输回执保存在 `attempt_diagnostics`，不得覆盖已发布 CORE。

评估报告同样分列当前产物与最新尝试：没有正式约束的草稿，其正式绑定数为 0，当前形状自由度为未知，不能借用失败候选的诊断。失败求解返回的 baseline 与当前模型恰好相同，不再被视为已接受求解与当前产物匹配。源半径数值正确、全部对象关系确定、独立 GT 精度通过仍是三个不同结论。

## 严格关系与完整性审计（2026-10-10）

已经准入的相切关系现在与精确半径、严格 OCR 角度一起求解：两侧单位切向量的叉积为零，点积必须为正，共享端点且有限图元不退化。最终数值证书为角度误差不超过 1e-7°、端点间距不超过 1e-7 图纸单位；这替代此前相切项允许 0.1° 的数值判据，不改变参考精度或源图误差门限。冗余等式使用局部 Jacobian 的独立行基参与优化，所有原始义务仍逐项验收。优化器返回成功、可行检查点和最优性证明分别记录。

导出时会重新计算模型几何及原生 DXF 的所有已准入 LINE–ARC、ARC–ARC 相切，不信任旧的 `passed` 标志，也不以 overlay 视觉接近作为证书。`reconstruction-contract.json` 另外列出所有相邻对象，包括未有关系证据的弧弧接点。没有证据的接点维持 unresolved，不被强制相切；所有半径正确也不再自动得到整个参数化阶段 completed。还需已识别标注覆盖、所有接点关系证书、数值约束、零剩余形状自由度及有效几何。此状态仅表示已识别源义务满足，不保证 OCR 完整发现或 GT 精度。

源笔画测量的观察孔径与允许偏离范围分开：可以扩大孔径观察完整粗笔画，但允许中心偏差、有效采样比例、局部两尺度一致性和接点方向证据门槛不放宽。短有限直线使用合适的有界支撑窗口；多笔画、空白、真实折角和支撑不足仍拒绝。

v14 将 raw-mask 导数的多尺度稳定性与跨侧夹角保留为诊断，不再用它提前阻止原图笔画检测。mask 仍用于定位共享节点与提供采样路径；关系准入必须来自两侧独立原图笔画，并继续满足原来的覆盖、两尺度 2° 与跨侧 3° 观察门槛。这是观察证据的门槛，不是最终 CAD 相切精度：被准入后仍须按 1e-7° 数值证书联合求解。没有原图证据、真实折角或目标区间不清时仍不准入。

半径引线增加了不依赖 API 初始位置的 OCR 局部候选搜索，复用完整箭杆、箭头、文字字形附着、全局归属与目标唯一性检查。每条最多 24 个源图初始候选、每个最多 24 个局部候选、8 秒预算；名义 R 不参与候选排序。若预算耗尽导致竞争候选未检查，已发现观察仅保留为诊断，不可据此宣称唯一归属或正式绑定。完整搜索结果仍须经过当前拓扑可行性、重新绑定、联合求解及 DXF 回读。

在线绑定从完整记录与候选生成最多四页，共享一次总超时。每条标注的候选组必须完整发送，后页关系不能静默丢失。记录实际发送、有效响应、未发送及失败页面；未发送或失败页面不能当作模型主动弃权。在线传输成功、源归属核实、数值通过、DXF 几何和独立 GT 精度继续分别报告。

角度箭头搜索覆盖完整 OCR 框附近，并使用原图实测支持线的法向寻找目标箭头。多个标注竞争同一条有限直线时，只有独立箭头证据能确认竞争者拥有该有限对象、且当前标注已有另一条独立箭头确认的直线，才排除延长线误配。名义角度不参与选对象；检测到方向并不等于可以直接使用拟合角度作为尺寸。候选必须重新绑定、联合求解并接受原生 DXF 复核。

工作台将严格相切和重建完整性分别显示，包含未知 ARC–ARC 接点和剩余自由度。显示只来自当前已发布 validation 证书，不从失败候选的最新求解回执升级当前结果；完整性旁路报告在发布回滚后也跟随当前 DXF 哈希。

单次 HDSA 冻结输入重解已证明原来的 12 个精确 R、4 个严格角度、8 处已准入严格相切能够同时满足原 mask 预算；它仍剩 23 个形状自由度。这个诊断不包含新 API 调用，不是完整在线流程通过声明。新一轮完整在线实验另有冻结输入、代码快照和评估回执。

本文描述当前候选实现的处理机制，不是完整自动重建或精度通过声明。条件性开发实验可使用已冻结的 GT 派生栅格 mask；它只提供材料边界观察、初始拓扑、数值初始化和既有边界误差预算。mask 可生成初始分段并影响候选数量，但不能单独认证最终设计对象数量、覆盖名义 R 与角度，或代替原图笔画及标注归属证据。比例、单位、闭合、自交、源笔画和原始 mask 预算继续分别检查。

### 数量、属性与关系怎样同时成立

对象数量和 LINE/ARC 类型是离散结构变量，半径、方向、圆心与端点是连续参数，不能先把拟合图元永久固定，再仅修改几个半径。每个结构候选需要重新建立标注归属，连同连接、方向和相切义务一起求解。若一个 ARC 同时承载不兼容的两个 R，应该生成局部分段候选；若斜线被粗 ARC 吞并，应该先根据有限直线笔画与角度箭头恢复 LINE。参数求解不能弥补错误的对象类型或遗漏对象。

已核实 R 通过常量消元保持精确值；已核实角度作为方向等式；共享节点提供连接关系；已准入相切同时要求两侧切向同向、叉积为零。原图与掩膜只提供结构观察、初始化和保真约束，不能覆盖这些已核实的名义值。没有唯一源证据的关系不能为了让图形平滑而强加。没有足够独立标注时，剩余自由度不会因拟合误差变小而消失，输出必须保留为未完全确定的草稿。

数量相同也不证明结构相同：一个错误合并和另一个错误拆分可能抵消总数。评估需分别检查类型数量、逐图元属性、邻接、连接、相切、标注覆盖和独立参考精度。精确半径证书只认证已绑定半径数值，仍需单独核实它绑定到了正确对象。

### 为什么对话中的模型表现不能直接代表 API 系统效果

本实验实际在线回执记录的模型为 gpt-5.6-sol。对话中的模型、可见上下文和操作权限未必与该调用相同，不能将两者视为已控制变量的能力比较。系统中的绑定器只能选择已有候选 ID；即使它理解图纸，也不能在绑定响应中直接补造漏掉的斜线、圆弧或尺寸。局部编辑器另有操作数与时间预算，并须通过本地原图证据和求解检查。

旧绑定请求还存在记录和关系截断：HDSA v11 仅发送了 16 条 OCR 记录、32 个绑定候选和 16 条关系。当前有界分页会记录完整候选库存、实际发送及未发送项。仍没有候选的标注不会因多发一次请求自动得到几何归属；这些缺口需由原图检测和拓扑编辑补齐。API 在线成功与标注覆盖、数值可行、全图确定性分别报告。

OCR 给出标注文字及名义 R、角度；在原图上核实文字关联、引线、箭头及其唯一目标后，R 才能成为正式精确约束：以参数消元固定为 OCR 名义值，半径容差为 0；端点圆周一致性、弦和 DXF 回读仍分别进行数值检查。角度还须有可核实的有限直线笔画、参考轴和箭头；粗圆弧吞掉该笔画时，局部执行器可依据原图恢复有限 LINE，再重新绑定角度。对 required、OCR 名义值且箭头已核实的单条 LINE 参考轴角度，求解器固定当前候选 LINE 起始方向的象限/支路；该象限由源图候选几何决定，施加名义角度等式并以 1e-7° 做数值证书；该数值证书不是工程允许偏差，其他未确认角度维持原有检查。两条 LINE 间的小圆角构造须保持箭头所指的精确 R 和两侧有限直线支撑，连接处区分记录原图独立相切证据与源标注圆角构造义务，仅认证实际具备的那类证据。后者只有在 fresh binding 核实同一源图哈希、当前半径箭头、两条有限 LINE 的原图笔画及构造几何后才进入求解；它不冒充独立的原图切线测量。整段 ARC 的原图支撑仍由拓扑及求解后源门禁检查。已绑定但不相切的小圆角可重新构造，再与角度一起求解。精确构造 R、正式绑定 R、已核实相切和最终 DXF 回读是不同回执。缺少证据时保持未解，不以近似拟合值或模型判断补证。

搜索可在三轮、宽度三、18 次预检、12 次模型调用和起始 600 秒拓扑预算内尝试不同的源图有效初始结构及局部组合编辑。已有完整数值、源证据及回归认证的进展，而且当前可信候选仍有可提议的源标注拓扑任务时，可在同一次搜索内追加一次最多 600 秒，总计最多 1200 秒；自定义短预算最多再加同额。轮数、预检、模型调用及 visited 状态不重置。追加时间只增加计算机会，不放宽几何或精度阈值，也不认证尚未求解的提案。预算原因、待处理操作与实际使用情况分别写入回执；不同预算实验不能声称计算成本相同。mask 和原图约束仍是硬门。每个进入数值预检的子候选按序尝试源检查、标注绑定、数值求解、求解后源检查及约束回归；前一关失败则后续不运行并记回执，只有完成全程的候选才可发布。未获数值预检的候选记为 not_run。未通过预检的探索结构不能发布，也不能把构造半径计入正式绑定覆盖。候选排序依据当前源证据及已满足约束，不读取 GT 图元数、坐标或评分。

源箭头唯一指向一个尚未绑定的 ARC、该 ARC 没有冲突尺寸、两侧为有限 LINE 时，即使旧拟合半径偏离标注，也可提出 LINE–ARC–LINE 重插。必须具备完整箭杆、箭头和源图可见性证据，不能仅凭模型建议或近似半径归属；构造还须通过切点所在旧 ARC 区域、有限直线、源路径和完整轮廓检查。提案本身不等于正式绑定，仍需新子图的 fresh binding、联合求解和 DXF 回读。

小圆角重插时，只有新 LINE 与原 LINE 同向共线、完整包含原有限直线段，且原见证明确来自源图时，才保留角度支撑线索；随后仍重新检查原图和箭头。它不是旧绑定结果的继承。

迭代调度先核查所有局部候选的源图支撑，再优先求解角度直线恢复及组合候选。只有完整预检、已有绑定不退化、几何有效且新增满足源标注，或在问题减少时实现有效对象简化的候选，才允许提前进入下一轮。主动延期的兄弟候选明确记录为 deferred_not_run，不计入通过，并保留余下轮次的重试资格；预算耗尽的候选另记 not_run_budget，不能保证在本次运行重试。

数值求解分别记录优化器是否收敛及候选是否独立可行。SLSQP 返回有限迭代点后，只有有限值、所有已绑定约束、严格角度、固定半径和弦、几何与完整掩膜边界预算全部通过同一点的复核，才可保留非收敛检查点；记录 optimality_proven=false，继续经过原图支撑和最终 DXF 检查。它不证明全图参数已经确定，也不证明找到了最优解。

预检对完整候选图建立输入身份并保持该图不变。绑定阶段新发现的角度观测和半径源线段仅保存为 **edit-only 提案线索**，供编辑器、局部操作和复合种子的临时副本使用；它们不回写已预检图，也不自动继承旧绑定结论。缓存只复用同一完整输入图的反馈。若绑定、求解或源检查意外改动预检工作图，流程 fail-closed：拒绝该预检，不写可信拓扑和输入身份证书。最终发布还须独立复核当前输入与约束，不能靠旧缓存或模型回执确认准确性。

GT DXF 仅在预测产物冻结后用于独立评估，不进入候选构造、约束绑定、模型请求或选优。原有 **0.1 mm 严格参考指标**与附加的 **1 mm 目标诊断**分别报告；1 mm 轮廓通过不替代 0.1 mm 结果，也不证明对象数、圆心、端点、邻接或全部标注正确。

当前圆角处理需要唯一源箭头、精确名义 R 和两侧有限 LINE；角度恢复需要源图直线、参考轴及可核实箭头，部分短斜线恢复还需要两侧已核实半径。证据歧义、源门禁失败或搜索预算耗尽均可能留下未解项。

本候选尚未保证完整自动化、全部约束覆盖或全部 GT 指标通过；在线传输成功、几何有效、参数准确和数据集覆盖须分别报告。冻结 v11 的 176 个 Python 文件与最终测试工作目录逐文件哈希一致，全套测试为 1384 passed、3 skipped（261.11 秒）。完整在线结果另存于 runtime 迭代报告，不以局部源内回放冒充端到端在线达标。

历史 v11 参数化阶段的 `completed` 只表示已绑定半径合同完成，不表示全部尺寸、相切或独立 GT 检查通过。当前候选已改为上述重建完整性合同；旧实验的历史状态保持原样，并按新严格标准单独复核，不追改旧回执。

## 仍未解决的约束表达缺口

本节数字来自 **V12 HDSA 冻结在线开发实验**，依据主项目 `runtime/cad-controlled-20261008/angle-semantics-v12-hdsa/after/` 内的 `binding-candidates.json`、`constraint-bindings.json`、已发布 `model.json` 及 `dimension-evidence.json`，并只查看其冻结原图与 OCR，不读取 GT DXF。它不是前文 V11 冻结输入的单次重解，也不引用 V14 的运行结果。以下修复建议是**尚未实现的下一步工作**，不能作为当前系统已具备完整尺寸求解能力的说明。

唯一成功绑定的线性尺寸是 `r031: 178±2`，表达为两节点的 `distance_y=178`。六条未绑定直径记录为 `r000: Φ840`、`r002: Φ740`、`r005: Φ264`、`r049: Φ186`、`r051: Φ264`、`r052: Φ740`，包含上下重复标注，只有四个不同的直径值。十四条未绑定线性尺寸为 `r007: (85)`、`r008: 25`、`r013: 10`、`r016: 19+3/0`、`r019: 135+5/+2`、`r028: 25+3/0`、`r029: 70`、`r033: 10`、`r040: 68+2/0`、`r043: 71`、`r046: 110`、`r047: 10`、`r050: (55)`、`r053: 380`。这里的正负偏差是原标注属性；是否按名义值、容差区间或参考尺寸使用，仍需明确的尺寸语义，不能按文字中的数值直接新增方程。

20 条未绑定记录中，**17 条完全没有候选约束**：6 条直径和 11 条线性尺寸。剩余三个长度记录虽有候选，但局部证据未通过：`r008: 25` 被关联到约 349 px 的长段，按比例应约为 141.58 px，且一端没有可靠站位支撑；`r019: 135` 与 `r040: 68` 各有两个候选，但均有一端为 `unsupported_projection`。在线绑定器只能选择合法候选，不能在响应中创建尚不存在的尺寸测量对象或约束类型。因此，这些缺口不能统一解释为在线模型没有理解标注。

### 为什么精确 R 和四个角度仍不能确定轮廓

V12 已发布轮廓有 22 个共享端点，对应 44 个坐标变量。12 个已绑定半径已作为常量消元；固定曲率并没有固定圆心、弧段跨度或切点。其余独立约束秩为 18，来自 4 个角度、1 个距离、6 个水平/垂直关系与 7 个严格相切关系。扣除不改变形状的两个整体平移自由度后：

`剩余形状自由度 = 44 − 18 − 2 = 24`。

这与冻结求解回执的 `variable_count=44`、`constraint_rank=18`、`remaining_dof=26`、`rigid_gauge_dof=2`、`remaining_shape_dof=24` 一致。30 条约束记录中包含已消元的 12 条半径，不能把记录条数直接当作对当前坐标变量的独立约束秩。计算实现位于 `contour_agent/parametric_solver.py` 的 `_model` 参数化与最终 Jacobian 秩审计。

完整性合同还列出 11 个未知连接关系：5 个 LINE–ARC、6 个 ARC–ARC。即使这些连接日后全部获得合法相切证据，且全部增加独立约束，仍至少剩余 13 个形状自由度；不能假设再执行一次圆角插入或重新设置 R 就能确定所有参数。重复尺寸、参考尺寸和新增辅助变量也会影响独立秩，后续必须重新计算，不能承诺“再绑定若干条记录就必然归零”。

### 缺少的是尺寸测量对象与相应方程

直径证据目前用于比例估计。V12 的 `dimension-evidence.json` 已识别 `half_section_radius_station`，比例约为 5.663104 px/mm，但尺寸绑定入口没有直径候选分支，求解器也没有径向基准站位约束。**知道每毫米对应多少像素，不等于求解时已经约束某条轮廓站位距旋转轴为 ΦD/2。** 重复的 Φ264、Φ740 还需要建立同一物理测量的关联，不能重复计为独立设计信息。

当前 `_length_candidates` 只在尺寸线端点附近寻找已有轮廓节点；本例候选搜索带为 8 px。求解器中的距离只支持两个已有节点之间的 X/Y 投影或欧氏距离。它没有把以下测量对象作为可绑定的通用表达：

- **径向基准与站位**：旋转轴、被测轮廓站位及半剖面直径关系；不能用图像原点或任意附近节点代替旋转轴。
- **虚拟交点**：两条有限直线的支持线延长后的尖角交点。插入圆角后，该点通常已不是轮廓端点，附近的短尺寸不能默认绑定到圆弧切点。
- **圆心及辅助定位点**：圆心到基准或其他辅助对象的轴向距离。冻结原图中的 110、380 等尺寸涉及轮廓外的辅助定位位置，需继续核实它们的尺寸线、引线和所属对象，不能强配最近轮廓节点。
- **曲线站位与投影厚度**：曲线上由设计语义确定的测量位置、极值点，以及沿任意已核实方向的两侧投影距离。斜向的 19 等厚度不能直接当作 X/Y 节点距离，也不能把图像测量点坐标硬锁为设计值。

两线角度是另一个尚未接通的通用能力：求解器已有两实体角和三节点角，但当前角度候选主要提供单条 LINE 相对水平/垂直轴的锐角。V12 HDSA 的四个 12°/15°均已绑定，所以这不是该例四个角度漏绑的原因；它仍是推广到其他图纸时需要补齐的表达链路。

### 短尺寸绑定不能继续复用长尺寸比例筛选

`contour_agent/dimension_evidence.py` 的 `_linear_witnesses` 原本服务于比例估计，只搜索 X/Y 方向，并要求笔画长度至少达到 `max(文字宽度×1.5, 图像最大边长×0.06)`。冻结原图最大边长为 3266 px，对应门槛约 195.96 px；按已估计比例，10、19、25 mm 分别只有约 56.6、107.6、141.6 px。短尺寸因而可能没有见证线，或被关联到合并后的长笔画。该全图尺度门槛不适合直接承担局部短尺寸绑定。

长度候选还要求延长线覆盖尺寸线到图节点的范围，并用已有节点构造站位组。尺寸延长线的正常留白、断开、文字遮挡，以及不存在真实轮廓节点的测量位置，都可能使合法尺寸保持未解。修复应根据局部文字、箭头、尺寸线和延长线建立有界的证据链，单独处理有证据的断口与倾斜方向；不能通过整体扩大支撑带、把多个候选强行合并或放宽 GT 误差门限绕过歧义。

### 下一步最小通用实现顺序

1. **建立尺寸测量对象表达层。** 支持实际节点、圆心、支持线交点、基准轴和有明确构造定义的曲线站位。辅助对象不必导出为轮廓实体；圆心和交点优先由现有几何参数计算，不引入任意的自由坐标，更不能以源图像素位置代替设计属性。
2. **先接通径向站位和投影距离。** 在源证据确认半剖面语义后，将直径表达为 `2×到旋转轴的有向距离=D`；线性尺寸表达为两个测量对象沿核实方向的投影距离。符号、轴方向、参考对象与适用区间必须明确，不能只按数值接近选择对象。
3. **分离比例估计与局部尺寸绑定检测。** 保留原比例估计的稳健长跨度见证，另为短尺寸、倾斜尺寸和有限断口构建局部箭头与延长线证据；每个候选记录为何存在、为何歧义或为何被拒绝。
4. **补齐未知关系证据，再联合求解。** 对 11 个未解连接继续核实有限对象与原图切线关系，已准入的关系仍按严格相切等式，与精确 R、角度和新增尺寸同时求解。不能为了消除自由度而把未知接点全部设为相切。
5. **按义务状态与独立秩驱动迭代。** 每条标注分别记录已绑定、重复测量、参考尺寸、外部规范依赖、歧义或暂不支持；`(85)`、`(55)`保留参考属性，所有未解项继续留在审计清单。候选进展应同时检查源证据、约束满足情况和独立秩增量，不能只看绑定数量或 overlay 误差下降。

在上述设计约束缺失时，坐标正则化和原始掩膜先验会从许多合法解中偏向靠近初始轮廓的一种形状。它们能限制漂移，却不能补出缺失的圆心、站位或测量关系。因此，继续调 R、增加迭代次数、修改先验权重，或把失败的 GT 精度门限放宽，都不能替代约束表达和证据链的补全。下一阶段仍须保持精确半径、已核实角度及严格相切，完成重新绑定、联合求解、原生 DXF 回读后，再用冻结预测做独立参考评估。
