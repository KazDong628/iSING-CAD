# 源标注控制的 CAD 重建：当前开发候选

本文描述当前候选实现的处理机制，不是完整自动重建或精度通过声明。条件性开发实验可使用已冻结的 GT 派生栅格 mask；它只提供材料边界观察、初始拓扑、数值初始化和既有边界误差预算。mask 可生成初始分段并影响候选数量，但不能单独认证最终设计对象数量、覆盖名义 R 与角度，或代替原图笔画及标注归属证据。比例、单位、闭合、自交、源笔画和原始 mask 预算继续分别检查。

OCR 给出标注文字及名义 R、角度；在原图上核实文字关联、引线、箭头及其唯一目标后，R 才能成为正式精确约束：以参数消元固定为 OCR 名义值，半径容差为 0；端点圆周一致性、弦和 DXF 回读仍分别进行数值检查。角度还须有可核实的有限直线笔画、参考轴和箭头；粗圆弧吞掉该笔画时，局部执行器可依据原图恢复有限 LINE，再重新绑定角度。对 required、OCR 名义值且箭头已核实的单条 LINE 参考轴角度，求解器固定当前候选 LINE 起始方向的象限/支路；该象限由源图候选几何决定，施加名义角度等式并以 1e-7° 做数值证书；该数值证书不是工程允许偏差，其他未确认角度维持原有检查。两条 LINE 间的小圆角构造须保持箭头所指的精确 R 和两侧有限直线支撑，连接处区分记录原图独立相切证据与源标注圆角构造义务，仅认证实际具备的那类证据。后者只有在 fresh binding 核实同一源图哈希、当前半径箭头、两条有限 LINE 的原图笔画及构造几何后才进入求解；它不冒充独立的原图切线测量。整段 ARC 的原图支撑仍由拓扑及求解后源门禁检查。已绑定但不相切的小圆角可重新构造，再与角度一起求解。精确构造 R、正式绑定 R、已核实相切和最终 DXF 回读是不同回执。缺少证据时保持未解，不以近似拟合值或模型判断补证。

搜索可在三轮、宽度三、18 次预检、12 次模型调用和起始 600 秒拓扑预算内尝试不同的源图有效初始结构及局部组合编辑。已有完整数值、源证据及回归认证的进展，而且当前可信候选仍有可提议的源标注拓扑任务时，可在同一次搜索内追加一次最多 600 秒，总计最多 1200 秒；自定义短预算最多再加同额。轮数、预检、模型调用及 visited 状态不重置。追加时间只增加计算机会，不放宽几何或精度阈值，也不认证尚未求解的提案。预算原因、待处理操作与实际使用情况分别写入回执；不同预算实验不能声称计算成本相同。mask 和原图约束仍是硬门。每个进入数值预检的子候选按序尝试源检查、标注绑定、数值求解、求解后源检查及约束回归；前一关失败则后续不运行并记回执，只有完成全程的候选才可发布。未获数值预检的候选记为 not_run。未通过预检的探索结构不能发布，也不能把构造半径计入正式绑定覆盖。候选排序依据当前源证据及已满足约束，不读取 GT 图元数、坐标或评分。

源箭头唯一指向一个尚未绑定的 ARC、该 ARC 没有冲突尺寸、两侧为有限 LINE 时，即使旧拟合半径偏离标注，也可提出 LINE–ARC–LINE 重插。必须具备完整箭杆、箭头和源图可见性证据，不能仅凭模型建议或近似半径归属；构造还须通过切点所在旧 ARC 区域、有限直线、源路径和完整轮廓检查。提案本身不等于正式绑定，仍需新子图的 fresh binding、联合求解和 DXF 回读。

小圆角重插时，只有新 LINE 与原 LINE 同向共线、完整包含原有限直线段，且原见证明确来自源图时，才保留角度支撑线索；随后仍重新检查原图和箭头。它不是旧绑定结果的继承。

迭代调度先核查所有局部候选的源图支撑，再优先求解角度直线恢复及组合候选。只有完整预检、已有绑定不退化、几何有效且新增满足源标注，或在问题减少时实现有效对象简化的候选，才允许提前进入下一轮。主动延期的兄弟候选明确记录为 deferred_not_run，不计入通过，并保留余下轮次的重试资格；预算耗尽的候选另记 not_run_budget，不能保证在本次运行重试。

数值求解分别记录优化器是否收敛及候选是否独立可行。SLSQP 返回有限迭代点后，只有有限值、所有已绑定约束、严格角度、固定半径和弦、几何与完整掩膜边界预算全部通过同一点的复核，才可保留非收敛检查点；记录 optimality_proven=false，继续经过原图支撑和最终 DXF 检查。它不证明全图参数已经确定，也不证明找到了最优解。

预检对完整候选图建立输入身份并保持该图不变。绑定阶段新发现的角度观测和半径源线段仅保存为 **edit-only 提案线索**，供编辑器、局部操作和复合种子的临时副本使用；它们不回写已预检图，也不自动继承旧绑定结论。缓存只复用同一完整输入图的反馈。若绑定、求解或源检查意外改动预检工作图，流程 fail-closed：拒绝该预检，不写可信拓扑和输入身份证书。最终发布还须独立复核当前输入与约束，不能靠旧缓存或模型回执确认准确性。

GT DXF 仅在预测产物冻结后用于独立评估，不进入候选构造、约束绑定、模型请求或选优。原有 **0.1 mm 严格参考指标**与附加的 **1 mm 目标诊断**分别报告；1 mm 轮廓通过不替代 0.1 mm 结果，也不证明对象数、圆心、端点、邻接或全部标注正确。

当前圆角处理需要唯一源箭头、精确名义 R 和两侧有限 LINE；角度恢复需要源图直线、参考轴及可核实箭头，部分短斜线恢复还需要两侧已核实半径。证据歧义、源门禁失败或搜索预算耗尽均可能留下未解项。

本候选尚未保证完整自动化、全部约束覆盖或全部 GT 指标通过；在线传输成功、几何有效、参数准确和数据集覆盖须分别报告。冻结 v11 的 176 个 Python 文件与最终测试工作目录逐文件哈希一致，全套测试为 1384 passed、3 skipped（261.11 秒）。完整在线结果另存于 runtime 迭代报告，不以局部源内回放冒充端到端在线达标。

参数化阶段的 `completed` 只表示该阶段的已绑定半径合同完成，不表示全部尺寸、相切或独立 GT 检查通过；须同时查看 `all_dimensions_verified`、`fillet_tangent_contract` 与独立参考评估。
