# 源标注约束补全与局部接触重建

本轮以原图、OCR 和 GT DXF 派生的二值掩膜为输入。HDSA65 与 044 都是已经曝光的开发样例，不能作为独立泛化证明。预测阶段不读取评估 DXF 的对象坐标；参考比较只在预测文件冻结后执行。

## 改动及其边界

1. **重新观察部分解。** 在已经通过联合求解的部分解上重新查找原图尺寸和接点。保留已核实的约束，最多补全两轮，每轮求解有独立时间限制。观察状态可以移动，原始掩膜预算、坐标变换和优化问题不随之重置。
2. **补回有限斜线。** 对有角度标注、两侧有独立半径箭头的区域，同时考虑 ARC–LINE–ARC。半径与角度来自标注；接触点、圆心和有限线段位置由几何方程及优化确定。
3. **解析构造接触。** 给定两个半径和直线方向，枚举至多 16 个解析分支，每分支 33 个初值及 48 次标量搜索。圆弧端点在圆上、连接处重合、两端有向相切均按方程构造。该结果仍然只是候选。
4. **把笔画检查提前放进搜索。** 不再仅生成掩膜误差最小的一个位置后就停止。搜索同时保留原图直线支撑可行的位置，之后仍执行原始整轮廓检查。离散笔画检查造成目标不连续时，保留已经可行的搜索初值。
5. **重新核实短斜线角度。** 原图检测到的笔画有限范围可能变化；不再要求新的 Hough 端点与旧端点相同。当前有限 LINE 仍须与原图同一笔画对应，两侧角度箭头仍须重新核实。
6. **保留独立备选初始解。** 如果更强的局部接触候选超出原始掩膜预算，同时保留另一份掩膜支持的初始化。前者不会覆盖后者；两者均须绑定、求解、检查才能发布。
7. **修正约束保留判定。** 带有有序测量锚点的尺寸，由锚点定义方向；遍历重编号引起的对象成员列表换序，不再被误判为尺寸方向变化。锚点、符号、值、对象身份和强制语义仍须一致。
8. **收紧 API 分页时限。** 某页耗尽共享时限后停止后续请求，保留成功页、草稿和缺失项。传输成功、结构成功、约束正确和参考准确率分别记录。
9. **按重新核实的箭头归属消除半径身份歧义。** 当一个旧 ARC 有多个 ARC 后代时，只允许具有同一源标注身份、精确值、强制语义和独立箭头证明的唯一新绑定建立对应。数值相近、自由拟合半径或另一记录均不能建立映射；跨后代的重复箭头归属仍然拒绝。

## 两类相切证据不能混同

原图笔画测量得到的接线方向，和源标注支持的设计接触构造，是不同证据。接触构造必须重新检查两个 R 的箭头与整个圆弧、角度的箭头与整条有限 LINE、实际半径及角度、实际有向相切、原图笔画和原始轮廓。

相切构造关系记录为 `source_bound_design_construction`，明确标记 `independent_source_tangent_measurement=false`。它不能作为一次独立原图相切测量计数。构造关系只有在对应两个半径和角度实际进入约束集合后，才可进入联合求解。

## 已定位的仍未解决问题

- **一对多身份映射尚未全部覆盖。** 两段旧 ARC 被重建成 ARC–LINE–ARC 后，粗粒度 lineage 会把三个新对象都挂到两个旧对象上。本轮已用重新核实的 R 箭头分别识别 R15、R65 后代；旧接点如果被新 LINE 展开成两个接点，仍不能用一个节点映射硬套。需要源证据支持的新关系替换证明，不能删除旧关系后直接声称成功。
- **观察图与已接受解仍可能来自不同阶段。** 某些重放使用上游初始 `topology.json`，而要求保留的约束来自已经优化的发布结果。其 R114 已经在发布结果中锁定，但初始图上的自由圆弧还需要重新求解，导致重新绑定先判为分段不足。必须在匹配的几何、绑定和求解收据上继续迭代，保留原始问题作为单独的校验域。
- **新增关系与已知约束的联合可行性不足。** 局部构造精确并不等于整个轮廓可行。若固定了不可靠的初始外端点，局部接触方程可能满足，但原始掩膜预算失败。应由联合求解移动未知位置，重新核实源证据；失败时保留上一份有效结果。
- **部分尺寸尚无可靠测量锚点。** 剩余形状自由度不为零时，位置仍受到初始值和观测误差影响。仅增加拟合权重不能替代明确的尺寸绑定。
- **044 的源标注与现有参考范围不同。** 原图右侧有 R6、R16、R13，而现有简化闭合 GT 及其掩膜未表达这些细节。这些记录继续留在未完成分母中，不能按参考轮廓删除，也不能把简化 GT 的对象数宣称为完整原图的正确对象数。

## 验收与复现

全量回归命令：`python -m pytest -q`。测试日志保存在 `runtime/cad-obligation-20261011/pytest-main-v*.txt`，历史失败日志保留。

实验代码冻结在 `runtime/cad-controlled-20261008/source-obligations-v*-code/`。完整重跑由 `scripts/run_controlled_iteration.py` 执行；最终阶段重放由 `scripts/run_source_obligation_replay.py` 执行。每次用新目录保存输入哈希、代码哈希、阶段进度、API 收据、候选、求解结果和导出文件。

`scripts/report_source_completion_iteration.py` 读取冻结收据并读回原生 DXF，生成汇总报告，不调用 API、不读取 GT DXF。完整重跑与重放分别列示。新增的 1.5 mm 参考比较与原有 0.1 mm 检查并存；精确半径、角度、相切和尺寸阈值没有放宽。

不能把 `completed_with_unresolved_attributes`、轮廓误差小于 1.5 mm、某个局部候选成立或 API 请求成功，表述为全部主轮廓重建已通过。最终指标以对应运行的冻结报告为准。
