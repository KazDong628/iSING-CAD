# 材料分割连通性改进与参数化重建入口

日期：2026-09-21。本文记录已实现的推理细化、实际执行的训练实验和分割消融评估；在线 API、约束求解和 DXF 对比应单独报告，不能由分割分数代替。

本次实际采用的是**同一模型在 768/1024 两个整图尺度上的边界概率融合**。没有实现或声称使用滑窗切块、独立局部模型或重新生成的 GT。分割连通性得到局部改善，但不意味着已经达到 GT 的图元数量、半径、连接关系或尺寸精度。

## 实现与数据边界

推理入口仍为 `contour_agent/segmentation.py` 的 `Segmenter.extract`。图像按比例缩放到最长边不超过 1536 的工作图，保留到原始图像的坐标映射；模型分别对整张工作图进行 768 和 1024 的保比例填充推理，再映射回同一个工作图坐标。

`contour_agent/segmentation_refinement.py` 只读取原始图像和两张预测概率图。融合规则在评估前固定：

1. 只在原预测边界附近更新，内部和远离边界的背景保持原概率。边界带半径为 `max(2, 6 * 工作图最长边 / 模型训练边长)`；1536/768 的设置对应 12 像素。
2. 边界带使用 `0.75 * 原尺度概率 + 0.25 * 高尺度概率`，阈值保持 0.5。
3. 最多 4 像素、且完全没有原预测前景支撑的新增孤立小点，恢复为原概率。已有独立区域不能被整块删除。
4. 如果候选使 4/8 连通域数增加、改变孔洞数、删除原有区域、修改超过原材料面积的 4%，或移除过多高置信度前景，则整次候选被拒绝。
5. 原图墨线支撑不能明显变差：边界到墨线的平均距离最多增加 0.05 个工作图像素，P95 最多增加 0.5 像素。
6. 如果两个旧区域变成一个新区域，连接必须经一次 3×3 侵蚀后仍能连接这些原区域；单点或仅角点接触不足以通过。

原图墨线还包括标注线、文字、箭头和剖面线，因此“接近墨线”只是有限的源图支撑条件，不能证明边界正确。规则也没有要求把所有图强制修复为一个连通域。

候选拒绝时返回原概率图，记录 `status=rejected`、`changed_pixels=0`，`after` 与原预测一致；候选诊断保留在 `proposed`。高分辨率推理发生 `RuntimeError` 或 `MemoryError` 时，记录 `failed_preserved_coarse` 并保留已完成的整图预测。资源失败不能被写成细化成功。

输出同时保留：

- `raw-prediction-mask.png`、`raw-prediction-overlay.png`：本次推理细化之前的模型输出。
- `prediction-mask.png`、`prediction-overlay.png`：实际采用的概率图阈值结果。
- `prediction-probabilities.npz`：原始与采用的概率数组，便于复查。
- `refinement.json`：接受/拒绝原因、4/8 连通域数、候选连接和像素变化。

注意：后续 `mask_geometry.py` 的 `material-mask.png` 是经过面积筛选的几何候选材料，不能与完整的 `prediction-mask.png` 混为一谈。其默认候选区域筛选阈值仍为 `max(3, 工作图面积×0.001, 最大区域面积×0.04)`，且当前几何候选主要导出外边界、诊断内孔。保留下来的 CAD 候选只有一个闭环，不代表完整分割已经连通。

最终实现新增了**筛选前的材料完整性门槛**：单独计算 4/8 邻域组件面积；完整材料检查只忽略小于 3 个工作图像素的噪点，不能使用上述较大的候选面积阈值隐藏断开的有效材料。只有一个有意义的 4 连通材料区域，并且得到一个有效外轮廓候选，才记录 `complete_exterior_candidate=true`。存在多个区域或仅角点连接时，仍保留可导出的诊断草稿，但记录 `automatic_completion=false`、`completion_class=incomplete_material_exterior_draft`；任务在几何检查通过时进入 `needs_review`，不能计为完整自动重建。参数化导出和恢复流程继续保留这个状态，不能因局部约束求解成功而覆盖它。内孔与尺寸正确性仍须分别检查。

`__dataset/` 保持只读。GT 只作为离线监督与推理后的评估标签，不作为在线推理、细化决策或 API 输入；没有把参考 DXF 坐标复制到预测。

## 实际执行的 12 轮微调

新增 `contour_agent/segmentation_topology_training.py`，在原 BCE＋Dice 基础上提供：

- 3×3 局部边界差异，权重 0.2。
- 4/8 两种邻域的软 Euler 局部差异和全局差异，权重 0.03。
- 忽略像素及其不完整邻域不参与损失，忽略位置梯度为零。

这是与目标材料拓扑相比较的可微正则，不是管状骨架假设，也不保证预测必定连通。连通域和孔洞可能抵消 Euler 特征，因此验证还独立记录组件数与孔洞数。

使用 `tools/finetune_segmentation_topology.py` 从原 `unet-r18-dxf-v2/best.pt` 热启动，训练 12 轮、batch size 2、输入 768、随机种子 142，耗时 144.69 秒，峰值 GPU 内存 1107.9 MB。只使用训练分区更新参数、验证分区选择模型；测试分区不参与训练或选模。保持现有整图仿射、翻转和标注噪声增强，没有启用局部裁剪训练。

选择规则在运行前确定：候选相对于已保留模型的验证 IoU 不降低，平均边界距离和连通域/孔洞计数误差不增加，且至少一项严格改善。初始权重本身也参加选择，不能因为已经训练就强制替换。
