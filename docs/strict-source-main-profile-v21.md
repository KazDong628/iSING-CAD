# 主轮廓重建：V20/V21 问题分析与修复边界

本轮在候选工作区修改，稳定主工作区暂不替换。线上结果以冻结运行清单、正式 DXF 的独立读回和冻结后的 GT 比较为准。HDSA65、044 是已反复使用的开发案例，不是独立留出集。输入为原图、OCR 和用户授权的 GT 派生二值掩膜；不把 GT 对象数、坐标或属性送入预测流程。

## 原因：问题在多个阶段之间传递

1. **对象识别缺少完整的标注语义。** 像素轮廓给出位置和邻接的初始假设，不能唯一决定 LINE/ARC 的分界。小圆角、短斜线和邻接大圆弧可被合并。API 提出修复也必须由本地执行器实际生成正确对象，不能只修改类型标签。
2. **正确箭头提议在绑定之前被覆盖。** 044 的源图重放中，R114 的正确 API 提议曾被另一条 R167 引线的局部 Hough 候选替换；R65 还受到另一条竖线的伪归属干扰。局部“找到箭头”和“这个箭头属于这条文字”不是同一判断。
3. **尺寸界线位置不是轮廓端点。** 一部分尺寸测量整个材料面、理论尖角、斜线内部的截面或参考基准。旧节点距离表达会把尺寸绑到拟合端点。单个端点到达目标也不能保证整个面方向正确。
4. **数值接受与严格标注不一致。** 044 V19 的 135 mm 约束实际为 134.99011426325546 mm，按旧节点尺寸的 0.05 mm 合同通过；这不符合用户要求的精确名义尺寸。
5. **候选搜索不能越过无效中间状态。** 不改变实际对象结构的拆分消耗预检预算；已满足硬约束、但暂未通过源图位置预算的合法候选，原来没有得到相同问题的受限重新初始化机会。
6. **完成状态只描述了子集。** 历史 HDSA V11 的 completed 主要表示半径子集完成，仍有未绑定尺寸及形状自由度。HTTP 成功、优化器停止、对象总数相同或 overlay 接近均不能证明完整自动重建。

## 本轮修改

### 严格属性与独立验收

新准入的源图距离和一般角度均标为硬约束，与已有严格半径、已核实轴角和 G1 一起求解。距离的数值证书阈值为 1e-7 mm，角度为 1e-7 度；这是浮点数值校验容差，不是放宽图纸名义值。历史没有声明为硬约束的节点尺寸保留历史合同，防止用新规则篡改旧实验。

导出前和导出后的原生 DXF 都重新验证，恢复旧任务时重新计算实际值。义务身份包含有序测量锚点与严格约束语义；一个旧的“通过”回执不能用来证明新的目标或不同测量位置。失败候选的半径、角度和关系证书不记到正式草稿上。

### 符号测量锚点

新增 `support_level` 和 `curve_extremum`，与已有两支撑线理论交点共同参与求解。

- 面位置锚点从当前未知 LINE 端点推导，且对应轴向关系必须严格满足。
- 极值锚点从当前未知圆心和半径推导，必须属于有限有向圆弧，不能使用圆上但弧外的点。
- 原图附着区间同时受实际观测笔画和有限 CAD 线段范围限制。拟合端点落在制图留白中不算独立源证据。
- 两段共线笔画之间的制图留白只在两端来源均可核实、间距有界时允许关联；不按标注数字选择端点或放宽全局容差。

源图重放中，两幅图目前各一条可靠长度从任意节点改为面位置关系。这是测量语义改进，尚不能称为尺寸覆盖率提升。内部测量截面、独立参考平面、旋转轴及直径站仍未完整表达。

### 拓扑搜索与箭头归属

无实际对象结构变化、无已核实半径重新分区的拆分提前退出；闭合轮廓的末段与首段也参与多半径区域分析。已有角度及组合修复候选保留优先槽位，再优先尝试实际实现标注修复的候选。

V21 保留经源图检验的不同物理箭头供全局归属选择；不在局部搜索阶段过早压成一个。即使只有一个文字记录声称某条引线，也必须具有文字字形与引线附着证据。歧义或来源不足保留为未决，而不是用距离最近或“没有竞争者”当作证明。

### 同一问题的受限重新初始化

只有几何有限、闭合、方向合法、硬约束经实际值复算通过，而源图位置预算失败的候选，才进入受限可行性恢复。最多两次从原图尺度推导的微扰重新求解原始图及相同约束；所有原图预算和 R/角度/G1/距离门限不变。共享时间与函数调用预算，超时后不得晋升；保存尝试及拒绝原因。

这是一种有限搜索策略，不是不可行性证明，也不保证两次尝试可以找到全局解。只有全部验收通过的候选才能替换正式产物。

## 尚未解决的结构性问题

两幅图均有六条直径记录尚未进入径向约束流程。直径尺寸可能定位材料面、内部虚线基准或理论截面，不一定对应圆弧直径。应首先通过原图确定共同旋转轴和测量位置，再建立 `x_i - x_j = (D_i - D_j) / 2` 等相对尺寸等式；不能把 D195.263 与 D186 因为邻近而绑到同一材料面。

044 的 69.85 上端属于法兰中的参考平面。被拒绝的轮廓顶点没有来源关联，拒绝本身是正确的。该处缺少的是参考平面的语义表示，而非更大的容差。输入主轮廓与原图完整外轮缘还存在范围差异；范围外或不确定标注仍保留在全量审计分母。

完整系统还需要基于源图的测量基准图、截面与实体的交点规则，以及缺失约束导致的形状自由度诊断。增加 API 调用次数不能代替这些数学对象。最终应分别验证对象一一对应、属性、邻接/相切、标注覆盖、有效自由度、几何合法性和独立参考精度。

## 试验与可追溯性

V20/V21 使用单独冻结的代码目录和输入哈希，执行同一完整在线流程。原始 OCR、有效 OCR、API 回执、候选拒绝、正式产物和代码身份都保留。独立 GT 评估在预测冻结后运行；求解和绑定不读取 GT DXF。

实测数字与全套回归结果见 `runtime/cad-controlled-20261008/strict-source-main-profile-review-20261010.html` 及同名 JSON。只有实际运行完成后才写入最终结论；本说明中的实现能力不替代真实两图的验收结果。

## V22：在线回归暴露的问题及修复

V21 两幅图完整在线管线均完成，但未发布满足源图预算的参数化结果。HDSA 保留 12 LINE＋9 ARC 草稿；044 保留 9 LINE＋10 ARC 草稿。它们的补充 1 mm 轮廓偏差检查通过，但对象类型数量和完整约束均未通过，不能称为准确 CAD。

### 搜索预算不应撤销已有物理证据

V20 的 044 R35 搜索已经取得两个完整校验的阳性观测，随后另一 seed 超出局部假设数量预算，旧函数却整组返回空列表。V22 将观测有效性和搜索完整性分开：保留已核实箭头及截断来源信息，对它额外检查全部已识别半径文字的字形、箭杆和归属竞争。存在歧义仍不能自动锁定。

在相同冻结 V20 原图、OCR/API 像素提议和预测图上的离线对比中，044 可靠半径绑定由 4 增加到 5，恢复 R35→g005。HDSA 源观测由 12 增加到 13，但可靠半径仍为 8；恢复的 R5 箭头指向 LINE，仍需拓扑生成。这是局部证据回放结果，没有新 API 调用，不能混入 V21 在线成绩。不同轮次的 API 像素提议不同，因此不能将一个回放的 R114 定位结果泛化到所有轮次。

### 保留真实失败阶段

旧通用异常处理把绑定完成后发生的预检失败重新写成 `binding_status=not_run`。V22 保留已绑定记录和约束数量，另存标准异常类别、失败阶段、求解是否开始/完成；不保存可能带敏感数据的原始异常文本。

V20 HDSA、044 各一次历史预检在写出 25、17 条约束后约 15、23 ms 即失败，同时总预算已经用完。原异常未保存，只能保守归因于“疑似绑定后预算耗尽”，不能追认无解。新的实际预算耗尽回归验证求解未被启动，同时绑定仍记为完成。

截图修正支路的纯拓扑输出也改为 `needs_review`，明确区分 `artifact_available` 与 `constraints_complete`。重启后仍需完整 CORE 一致性及原生 DXF 回读，不能凭文件存在或旧完成标签取得标注认证。

### 固定五轮并不等于预算耗尽或问题不可行

V21 两图的六次最终求解均在固定五轮源轮廓见证点细化后停止。每轮 SLSQP 对当时加入的约束返回成功，已绑定尺寸与几何检查也通过，但完整曲线仍有违反源预算的位置。总共仅约 99、118 次目标调用和 33、35 秒，低于共享 120 秒/30000 次预算。

原可行性阶段最小化的是相对初始节点的位移；完整轮廓验收前尚未进入源图 RMS 精修。每轮只补充有限正向和反向见证点，局部检查点合格不能证明整条曲线合格。V22 在原时间和函数调用预算内继续加入实际违反且尚未加入的位置，最多24轮；记录预算、轮数上限、无新增见证等退出原因。最大误差暂时不下降但仍找到新违反点时，不提前停止。

可选 RMS 精修最多使用5秒，并为后续核验预留5秒；其子预算到期保留先前已经独立验证的可行解，不声称达到最优。最终完整源图、约束及原生 DXF 核验仍然必须通过。

同一冻结 V21 数值问题的最终代码离线重放：HDSA 第9轮达到0.668208613 mm，小于原门限0.669669029 mm；044 第7轮达到0.765297997 mm，小于原门限0.826603880 mm。两例前5轮均与旧代码相同，分别用时26.7秒和21.2秒。这证明固定轮数阻断了这些输入的可行解搜索；它不是完整在线重建、对象数量正确或所有标注满足的证明。完整在线结果另列。

### 正式产物与失败尝试的网页回执

V22 预测冻结后，另修复网页回执归属：正式对象读取 `model.json` 中的提交阶段、已绑定记录及求解证书，最后一次尝试放入独立 `attempted` 栏。V21 HDSA/044 的正式拓扑草稿现在显示0条已认证绑定，同时保留失败尝试的11/37、10/35条绑定及对应自由度，避免把失败候选误当下载DXF的属性。预检错误只透出阶段、标准类别和是否启动求解，不展示原始异常文本。

这属于独立展示补丁，没有修改V22冻结预测源码和结果；27项针对性回归通过。旧任务没有正式产物身份时明确标为 `latest_attempt_without_publication_identity`。
