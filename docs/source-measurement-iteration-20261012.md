# V77：原图测量位置与共同圆心的迭代

本轮从已冻结 V75 状态继续。两张图仍是已曝光开发样本，使用 GT 衍生的栅格掩膜，复用上游 OCR 和拓扑。新运行重新调用在线 API 检查标注、绑定及求解，不能算完整网页端到端重建或新样本泛化测试。GT DXF 不进入预测和 provider，只有预测冻结后的独立评估进程可以读取。

## 真实缺陷与修复

### 1. 短箭头局部方向不等于远端圆心方向

044 的 R180、R160 引线尾部在原图终止于同一圆心，但原检测主要使用箭头附近短 Hough 线段方向。该小方向误差经远距离外推后，导致两条短射线没有汇聚到实际笔画共同终点，后续 105、351 的测量对象无法表示。

新增 `source_measurement_tracks.py`，只用原始像素重测长半径引线。箭头所有权和短方向限定搜索范围；算法沿有界路径收集孤立细笔画，检查跨度、方向稳定性、拟合残差及与原箭尖的关联。只允许当前半径自身 OCR 框作为显式遮挡，不把遮挡算成笔画支撑。缺失或歧义轨迹不能无限跨越；两条引线仍必须通过独立的整段可见支撑和有限终止检查，继续穿过交点的线不构成圆心证明。

本轮 044 原图诊断：R180 长引线观测跨度 630 px，方向相对短段改变约 0.9165°；R160 观测跨度 507 px。恢复的源圆心约为 (1495.878, 1233.660) px。此像素位置只用于尺寸端点关联，绝不固定为 CAD 圆心坐标。

### 2. 一个源圆心对应多个 ARC 时，需要显式关系

过去同一源终点分别返回多个 `curve_center` 候选，候选竞争可能使尺寸无法绑定；选择其中一个也不能保证另一个圆弧共心。

新增 `common_curve_center` 符号测量点。只有两条独立归属的半径引线均实际终止于同一点、且分别唯一指向不同 ARC 时，才生成该点。它引用两个 ARC，并将 `Cx1=Cx2`、`Cy1=Cy2` 加入精确方程。尺寸测量读取当前求解圆心，不读取原图位置。两条共心方程同时进入优化、可行点复核、约束秩分析和原生几何回读。

如果另一条引线的 ARC 目标仍有歧义，不能推出共心。两个无限支撑线的交点、同一个物理箭头重复使用、源码断线和不属于当前记录的 OCR 遮挡，也不能获得共同圆心证书。

### 3. 长尺寸误选了更远的交线

044 的 351 尺寸，旧逻辑要求远端延伸线长度大于 OCR 标签高度的两倍。实际圆心短延伸线被过滤，随后选中了更远的 105 竖向尺寸线，产生错误的区间和 `source_span_nominal_conflict`。

新增已关联长尺寸轴线上的有界箭头站位搜索。只有同一尺寸轴线上的两个相对箭头均通过原图检查，才替换旧区间；候选短延伸线长度不再由标签高度两倍这一条件排除。候选排序不使用尺寸值或 CAD 坐标。竞争区间保留为歧义，普通交叉线不能替代箭头。

044 的旧区间为 x=115 到 1554.5 px；两个真实箭头确认的新区间为 x=114.5 到 1496 px。新候选依照已声明的半剖面语义，用独立源直径参考消去公共轴线，将 351 表达为直径参考与当前共同圆心之间的方程。参考直径依赖仍单独披露，不能冒充绝对轴线已独立求解。

## 当前算法边界

上述修复扩展了原图测量语义，不是从 GT 补坐标。它没有宣称解决所有局部拓扑：044 的右端 R16/R13 仍需要独立箭头归属及有限源轮廓证据，缺失对象不能靠连续优化自动长出来。HDSA 的尚未核实相切、短尺寸和原图支撑发布冲突也需要单独处理。

本轮没有启用由缺乏证据的中间站位任意串联得到的新尺寸方程。只有已独立核实的测量位置才能作为精确约束；尺寸链的一致性和缺项通过报告中的符号测量关联图披露，不能把初始拟合位置或未经证实的共线关系当作来源。
