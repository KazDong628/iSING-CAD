## 当前问题与下一步

1. CL60文字造成的假凹陷已减轻，但右侧仍有伪小弧和局部阶梯；图元55仍多于GT24。下一步应把连续曲率段和相邻真实圆角作为成组拓扑假设比较，不能只追求更少图元。
2. 本轮识别120条候选尺寸，只有8条进入采用解，112条未绑定。还需要共享基准的直径关系、角度和圆角插入/合并，并为每个绑定保留引线和源文本证据。
3. OCR曾将变量Δ1识别为41；已用首字形三角形/无数字4竖尾证据阻断，并要求API抄录源图标注。其他符号混淆仍需更全面字形或OCR证据。
4. 202的局部闭合范围与参考简化轮廓存在明显差异，单靠当前已绑定尺寸不会消除24 mm级最大误差。应继续依据源图明确主轮廓范围，不能读取GT后照抄其闭合边。
5. 分割边界、源笔画校正、数值约束、参考精度必须分别评估。后续应以整图闭合、图元类型/连接匹配、尺寸覆盖和独立误差共同衡量，而不是只看分割IoU或HTTP成功率。
