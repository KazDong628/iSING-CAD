# 完整掩膜条件下的重建迭代：2026-09-27

本轮将 GT 派生的栅格掩膜作为输入，暂时隔离分割误差。预测阶段只使用原图、OCR、栅格掩膜和源图证据，不读取 GT DXF 图元坐标。先冻结预测，再运行独立 DXF 比较。CL60-main、044-main 均作为开发样本；数据集共 50 张，其余 48 张未在本轮测试。

## 已修复的退化路径

- 半径引线不能仅因距离近而通过。检查从文字框到箭头目标的路径及中途轮廓交点，剖面线形成的错误穿越保持为未确认候选。
- API 选择、弃权只作用于实际发送的 ID。未进入请求包的标注保留本地证据判断，不能当作模型已拒绝。
- 闭合轮廓的数组首尾属于同一物理边界时，按原有拟合预算检查合并，避免数组起点产生多余图元。
- 候选验证失败后，使用同一门限检查其他已允许候选和原始草稿，保留每一步拒绝证据。
- 完整掩膜实验关闭普通分割修补所用的笔画拉直、遮挡绕行和粗化。044 原先有一处拉直偏离原始边界约 7 px，导致后续精度退化。
- 后续候选及参数求解始终对照最初掩膜的边界和预算，不能以中间拟合重置误差基准。超限时保留上一份有效草稿。
- 增加尺寸文字在线解析回执，以及初始 CAD、拓扑、参数候选、发布文件的逐阶段独立比较。
- H800 复测发现多模态阶段输出截断，将 Anthropic 规划、绑定、评估预算设为 8192 tokens，编辑设为 12288；尺寸仍为 2200，其他协议、请求次数和最多 600 秒时限保持不变。记录实际预算及数值 token 用量，截断内容不进入几何执行。

## 事后误差归因

只读核对冻结配准与已导出文件后发现，CL60 掩膜配准的等向比例为 5.804329882 px/mm，而预测从源标注得到 5.847089947 px/mm；二者往返比为 0.992686949，约缩小 0.7313%。实际发布 DXF / GT 周长比为 0.992930141，约缩小 0.7070%，与整体比例效应相符。掩膜配准另含 0.347390° 小旋转，输出的两条长侧边相对竖直约偏 0.307° 和 0.293°。因此 CL60 的 1.940948 mm 不应全部解释成局部分段错误；目前 D4 加平移评分保留了这些整体偏差。

044 的掩膜配准比例与预测比例同为 3.938834996 px/mm，小旋转为 0。其剩余 0.386716 mm 主要需从局部分段和切点定位检查，尤其左侧斜线与 R35、左下短线与 R65 的接头。两例均没有证据支持将误差归为掩膜的各向异性缩放。

局部参数审计进一步显示：044 的 R65 半径已接近参考值，但圆弧吞并了本应独立存在的短直线；右上斜直线被约 R492 的大圆弧覆盖，R114 局部被约 R70.9 的弧贴合。CL60 左上小圆角处仍出现短直线，左下斜直线被大半径圆弧覆盖。这些是独立于整体比例的对象类型、切点及参数错误，不能通过全局配准解决。

两例冻结二值掩膜宽度均为 1536 px，每个掩膜像素分别约对应 0.365 mm、0.376 mm；0.1 mm 仅约为 0.27 个掩膜像素。完整分割并不等于无限精度的几何边界。亚像素拟合可能改善，但仅凭栅格贴合不能认证 0.1 mm；需要标注尺寸和正确的相切、连接关系恢复解析图元。

以上配准信息仅用于**预测冻结之后的原因分析**，没有反写预测、没有校正 DXF，也没有用新的缩放或任意旋转评分替代原门限结果。下一步尺度与方向的修正必须重新从原图标注及轴线建立证据。

证据为两例 `evaluation/comparison.json` 的 `error_localization` 与实体参数、`evaluation/summary.json`、`after/model.json`，以及评估侧只读的 `runtime/segmentation/gt-data-v3/manifest.json`。评估实体 `p…` 编号不能直接当作网页拓扑的 `g…` 编号。

## 当前主要缺口

1. **约束覆盖不足。** 当前绑定器生成长度、半径候选；直径与角度已计入分母，但对应候选生成尚不完整。应先补齐来源于原图轴线、尺寸线、延伸线和角度端点的证据链，而不是单纯扩大 API 输入或增加求解次数。
2. **标注站点与拓扑节点不是同一概念。** 尺寸可能指向圆弧上的切点或内部站点，不能强行绑定最近分段节点。需要有源图依据的站点定义与求解约束。
3. **小圆角及 LINE/ARC 分解仍不完全正确。** 应结合指向性标注形成局部候选，经几何执行器与独立检查比较，避免把轮廓光滑度当作对象数量的唯一依据。
4. **尺度和原点尚有歧义。** CL60 的直径与线性尺寸尺度交叉验证未通过既定门限，不能凭预测与 GT 接近就补定轴线。评分中的配准不能回写预测坐标。
5. **公差目标和未标注几何。** 名义值、公差中点与参考建模约定可能不同；必须提前声明，不能在看到 GT 后选取更接近的目标。未标注且欠约束的过渡段不应宣称唯一恢复。
