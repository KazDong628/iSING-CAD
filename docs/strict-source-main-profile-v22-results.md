## 一直无法解决的原因

1. **图像对象和设计对象未必相同。** 光滑掩膜可被多种LINE/ARC序列近似，低像素误差不能确认真实对象数量。标注要求的斜线、小圆角、多半径段必须能改变离散拓扑；固定现有对象类型只优化坐标无法产生它们。
2. **局部候选构造仍限制未知量。** 多R分区仅允许有限ARC组合，常固定链外端点；斜线恢复和圆角构造先检查拟合尾段和原方向。正确的名义角度、圆角及相切联立后才可行的组合，可能在联合求解前被筛掉。
3. **标注可识别，但测量对象缺失。** 两图各有六条直径尚未形成共同旋转轴与测量站约束。内部参考平面、斜线截面及极值不是任意轮廓顶点，不能强行绑定最近点。已识别标注全部保留为义务，但OCR完全性尚没有证书。
4. **连续求解有提前停机缺陷。** V21固定五轮见证点细化，每轮当前检查点通过但完整曲线失败；两图仍有剩余预算。重新初始化也重复五轮，不能排除同样缺口。
5. **证据和搜索预算混在一起。** 后续OCR局部箭头搜索截断会清空之前已经完整验证的阳性，导致044丢失R35。已核实证据不应因另一个搜索分支未完成而消失。
6. **候选调度未覆盖关键分支。** V22 044的24°斜线候选已生成，但本轮剩余时间不足以预检；HDSA经历两轮认证进展并获既有策略的条件加时，044未获得同样机会。不能用“未测试”推断“无解”。
7. **部分合同通过曾被误读为完成。** 已绑定子集的严格R、角度或G1通过，不代表所有标注已覆盖；失败候选的数值证书也不属于正式DXF。旧网页回执混合这两种归属，已另行修复。

- 源图距离及一般角度按名义值硬等式求解，独立DXF回读阈值为1e-7mm和1e-7度；已核实R严格保留原名义值，严格G1继续按原合同检查。

## 后续完成路线

先建立逐条源标注义务表，把未决项分为缺原图证据、缺测量基准、缺对象、绑定歧义、数值不可行及尚未预检，并给出具体下一操作。随后用标注驱动LINE/ARC对象组合和小圆角生成，让父线角度、圆心、切点及相邻支撑共同作为未知量，统一进入名义值/G1等式求解，减少固定拟合端点的局部筛选。

最后补齐旋转轴、直径站及内部测量平面图，利用自由模式定位缺少的独立约束。完整验收同时要求对象一一对应、类型、所有已知属性、相切/邻接、零剩余形状自由度、原生DXF复核和独立GT精度。原始0.1mm检查和用户补充1mm检查并列保存，源图及严格标注门限没有放宽。
